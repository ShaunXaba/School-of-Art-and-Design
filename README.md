# School-of-Art-and-Design
This web application made with HTML and CSS is an online art and design school called SOAD, targeted at people how would like to enroll and study at their own time.

# Who was this make for?
This app is for those who has a job that doesn't satisfy them and need a career change, but can't just quit and go back to school, so with SOAD, people can attend classes at their own time, while still working, and at the end when they get their degree, they now have the access to choose a new career path.   

# Tools and language used
-	Built on vs.code
-	Uses HTML and CSS
-	Can be accessed on your preferred web browser

# Website navigation
Landing/home page (index.html) would have the different navigation options (Home, About Us, Courses, Contact). Scrolling down you see a short introduction of the courses offered, the campus locations and enroll that takes you to the contact page. 

About us page gives a description of the school with the “Explore” button taking you to the “Courses” page, where you will see the courses, and details on the different courses.

Lastly you land on the “Contact” page where you can see a map of campuses, contact information, and a form to fill out to start the enrolment process. Once the form is filled out, both the student and school should receive a message. For the student, it would be a confirmation email, and for the school, it would be and email with student’s information.
